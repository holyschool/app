<h2 align="center">Build</h2>

<p align="center">Requires JDK 17 and the Android SDK.</p>

<div align="center">

```bash
./gradlew :app:assembleDebug
```

</div>

<h2 align="center">Project layout</h2>

<p align="center">
  <code>app/</code> — the Android application<br>
  <code>edupage-lib/</code> — pure-Kotlin EduPage API client used by the app<br>
  <code>gradle/</code> — version catalog and wrapper
</p>
